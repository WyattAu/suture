# Code of Conduct

This code of conduct applies to all contributions to the Suture plugin marketplace, including plugin submissions, reviews, and community discussions.

## Expectations

- Be respectful and constructive in all interactions.
- Provide clear, accurate metadata for any plugin submitted.
- Do not submit plugins that contain malicious code, tracking, or data exfiltration.
- Respect the intellectual property rights of others. Only submit plugins you have the right to distribute.
- Report security vulnerabilities privately rather than through public channels.

## Enforcement

Violations of this code of conduct may result in removal of plugin listings or restricted access to the marketplace. Reports should be directed to the Suture maintainers via the project's security contact listed in `SECURITY.md`.
